# Exponit Labs Project Context (`exponit-elephant`)

This skill acts as the architectural anchor and context loader for the **Elephant** (the deep-context specification and design agent) when planning, drafting, and evaluating changes to the **Exponit Labs** codebase.

---

## 1. System Overview

Exponit Labs is a unified Laravel application serving four primary domains from a single codebase:

1. **Public Marketing Website (`/`)**:
   - Server-rendered Blade views, SEO/AEO-optimized, JSON-LD structured data via `spatie/schema-org` (`App\Support\Seo`).
   - Contact form with honeypot protection (`spatie/laravel-honeypot`) and Discord alerts.
   - Dynamically generated `sitemap.xml`, `robots.txt`, and `public/llms.txt`.
2. **Admin Console CMS (`/console`)**:
   - Built on **Filament v5** and **Livewire v4**.
   - Manages Therapeutic Areas, Products, News Posts, Contact Submissions, AR Creatives, Doctors, and Microsites.
3. **Augmented Reality Viewer (`/ar/{creative}`)**:
   - MindAR image tracking + Three.js viewer.
   - Mind tracking files (`.mind`) compiled in-browser and stored with QR codes generated by `endroid/qr-code`.
4. **Doctor Microsites (`/dr/{slug}`)**:
   - Shareable per-doctor landing pages (profile, showcases, reviews).
5. **Local-First MR Field App (`/mr`)**:
   - Mobile-first field tool for Medical Representatives (MRs).
   - Designed for offline operation using **Dexie.js** (IndexedDB), Service Worker caching, and client-side UUID generation.
   - Independent of the Filament panel to avoid layout bloat and latency.

## 2. Technology Stack & Runtime

- **Language / Framework**: PHP 8.4, Laravel 13 (`laravel/framework` v13)
- **Admin Panel**: Filament v5 (`filament/filament` v5), Livewire v4 (`livewire/livewire` v4)
- **Frontend / Styling**: Tailwind CSS v4, Alpine.js v3, Vite 8, Blade templates
- **Database**: SQLite (both local development and production)
- **Local Server**: Laravel Herd at `https://exponitlabs.test`
- **Testing**: Pest PHP v4 (`pestphp/pest`)

## 5. Architectural Invariants & Rules

1. **Test-First with Pest**:
   - Every behavior change must have an accompanying automated test in `tests/Feature/`.
   - Run tests with `php artisan test --compact`.
   - Do not rely on ad-hoc tinker scripts when tests can verify functionality.
2. **Filament v5 Conventions**:
   - Use static `make()` initializers and typed properties (`$navigationIcon: protected static string | BackedEnum | null`).
   - Use correct v5 namespaces: `Filament\Schemas\Components\` for layout (`Section`, `Grid`), `Filament\Actions\` for actions.
3. **Database Inspections**:
   - Always inspect table schemas using the `database-schema` tool before writing migrations or models.
4. **Code Formatting**:
   - Run `vendor/bin/pint --dirty --format agent` after modifying PHP files.
5. **No Blind Full-Tree Scans**:
   - Reviewers and Elephants should read targeted files or contracts rather than reading entire directory trees.
