# Filament Administration Subsystem Blueprint

## Overview
Coordinates the Filament v5 CMS administrative console operating under `/console`, including resource models, custom form components, dashboard widgets, and auth pages.

## Subdirectories & Boundaries
- [Forms](./Forms/EGM.md): Custom form components including interactive spatial location map pickers.
- [Pages](./Pages/EGM.md): Custom administrative and authentication profile pages.
- [Resources](./Resources/EGM.md): Administrative CRUD resources for website content, field force reporting, and catalog management.
- [Widgets](./Widgets/EGM.md): Dashboard and analytic map widgets.
